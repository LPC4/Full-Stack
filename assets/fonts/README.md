# Bundled fonts

Embedded into the binary (`include_bytes!`) so the IDE renders identically on native
and wasm. Both are licensed under the SIL Open Font License 1.1.

- `SpaceGrotesk.ttf` - Space Grotesk (Florian Karsten). Chrome / UI labels.
- `IBMPlexMono-Regular.ttf`, `IBMPlexMono-Medium.ttf` - IBM Plex Mono (IBM). Code / data.

Sourced from the Google Fonts repository (`github.com/google/fonts`, `ofl/`).
See the OFL: https://openfontlicense.org
